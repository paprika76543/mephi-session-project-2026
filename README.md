Пункт 3.1. Через lsblk убедился что второй диск это /dev/sdb и он пустой. Отформатировал через mkfs.ext4 -L MEPHI_WEB /dev/sdb1 и проверил через blkid, там LABEL="MEPHI_WEB" TYPE="ext4".

Смонтировал вручную командой mount /mephi-web без указания устройства, он берет запись из fstab, так заодно проверяется что строка в fstab правильная. mount подсказал сделать systemctl daemon-reload, сделал. Проверил через findmnt /mephi-web. Файл fstab в репозитории.

Пункт 5.1. Сначала выставил политику паролей из пункта 6.2, чтобы она сразу применилась к новым пользователям, об этом ниже. Потом создал две группы, groupadd developers для разработчиков и groupadd -g 4444 curators для кураторов. Группы developers в задании нет, я ее завел сам, потому что без общей группы нельзя сделать чтобы все три разработчика писали в файлы друг друга. Пользователей создал через useradd -u 5501 -G developers user1 и так же user2 и user3 с 5502 и 5503, кураторов useradd -G curators curator1 и curator2. Проверил через id для каждого и getent group. Пароли задал через passwd для каждого, пароли 12 символов и больше. Срок проверил через chage -l, у всех Maximum 90.
Каталог создал mkdir -p /data/mephi-2026, отдал группе chown root:developers, права chmod 2770, то есть разработчикам все, остальным ничего, и бит setgid чтобы новые файлы получали группу developers. Для кураторов обычных прав не хватает, у каталога одна группа, а кураторам нужно только чтение, поэтому добавил ACL. setfacl -m g:curators:r-x на сам каталог и setfacl -d -m g::rwx,g:curators:r-x,o::--- как default, чтобы те же права наследовались на все файлы которые будут создаваться. Без default ACL новый файл получил бы права по umask создателя и user2 не смог бы писать в файл user1. Результат в getfacl.out и в stat.out, там 2770.
Проверял так, все от root через sudo -u. Каждый разработчик создал свой файл, потом каждый дописал в чужой по кругу, user1 прочитал файл user3, user2 создал подкаталог sub и user3 дописал в файл внутри него, то есть наследование работает. curator1 и curator2 прочитали файлы и подкаталог и сделали ls, а запись в файл, touch нового файла и rm дали Permission denied. От nobody и ls и cat каталога дали Permission denied. Потом ls -lR и getfacl на файл, у файлов rw-rw----+ и группа developers, у кураторов effective r--.
